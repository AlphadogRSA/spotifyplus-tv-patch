# Hush TV Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Add opt-in Hush restart skipping to the existing TV application.

**Architecture:** A pinned upstream Hush companion receives trusted native ad flags and session tokens from the MIT TV extension. The companion owns restart/recovery; the extension retains player-local mute and persists its timer.

**Tech Stack:** Java 8 extension, Java 17 Android companion, Android SDK 35, Python preparation script, Kotlin ReVanced patches.

**Spec:** ../specs/2026-10-27-hush-tv-design.md

## Global Constraints
- Spotify TV 1.134.2; Android 8+; same signing key for companion and TV app.
- Pin upstream 4e9ded397338de5c69b1784c636feb3d34a8de01; retain GPL notices.
- No global-volume mute, arbitrary external commands, private keys or original APKs in git.

## Review Focus
- Duplicate native callbacks must not trigger restart loops.
- Late/stale tokens must not replace an active new session.
- Missing companion or helper leaves player-local muting usable.
- Sleep deadline expiry must suppress restart and survive Spotify process death.
- Signature checks must guard both incoming commands and outgoing session tokens.

### Task 1: Companion preparation and skip policy
Files: `hush/prepare.py`, `hush/overlay/`, `hush/tests/`, upstream gitlink.
Interfaces: `prepare(destination)` creates an adapted Android project; `TvSkipPolicy.shouldSkip(...)` latches attempts until real music resumes.
- [ ] Add and run failing preparation and policy tests.
- [ ] Implement reproducible pinned preparation, native-signal receiver, remote setup and session adapter around Hush's skipper.
- [ ] Run preparation/policy tests and Android Gradle tests/build.

### Task 2: TV integration and timer continuity
Files: `HushClient.java`, `Hooks.java`, `SleepDeadline.java`, manifest patch, `tests/SleepDeadlineTest.java`.
Interfaces: `HushClient.signal(context, token, ad, sleepAt)` sends trusted state; `HushClient.open(activity)` opens companion; `SleepDeadline` validates persisted deadlines.
- [ ] Test deadline expiry and restart restoration before implementation.
- [ ] Add companion launch, session/ad forwarding and persisted timer.
- [ ] Compile extension and run original deterministic/presentation tests.

### Task 3: Build, installation, documentation and CI
Files: `build.ps1`, `install.ps1`, Hush build script, `.github/workflows/test.yml`, `HUSH.md`, notices/handoff.
- [ ] Build/sign companion with same retained key; install before Spotify splits, with no uninstall/data reset.
- [ ] CI prepares pinned upstream, runs all companion unit tests and builds an APK artifact.
- [ ] Record measured checks separately from pending device tests; review diff and publish a reviewable PR.
